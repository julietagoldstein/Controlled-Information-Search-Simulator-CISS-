Instrucciones para jugar al SET

Regla para formar un SET

Para formar un SET, cada característica (forma, color, relleno y cantidad) tiene que cumplir una regla.

Esa regla dice que las tres cartas tienen que ser: o todas iguales, o todas distintas en esa característica.

Si todas las características cumplen la regla, las cartas forman un SET.

Pero, si alguna característica no cumple la regla: (o sea, si en alguna característica no son ni todas iguales ni todas distintas), entonces las cartas ya NO forman un SET.

Veamos algunos ejemplos
1) Todas iguales

Tenemos que responder si estas tres cartas forman un SET o no.

Podemos ir viendo para cada una de las características, si se cumple o no la regla.

Las cartas tenían que ser todas iguales o todas distintas en cada una de las 4 características

- Empecemos con la forma. Se cumple la regla “todas iguales o todas distintas” porque tienen todas la misma forma: son todas óvalos.

- Sigamos con el color. Se cumple la regla porque tienen todas el mismo color: son todas verdes.

- Ahora el relleno. Se cumple la regla porque tienen todas el mismo relleno: son todas así, todo pintado.

- Por último la cantidad. Se cumple esta regla también porque todas las cartas tienen una sola figura.

Entonces, como la regla se cumple para todas las características, estas tres cartas forman un SET.

2) Todas distintas

A ver en este ejemplo:

- Para la forma, se cumple la regla “todas iguales o todas distintas, porque tienen todas formas distintas: óvalo, diamante y viborita.

- Sigamos con el color. Se cumple la regla porque tienen todas colores distintos: verde, azul y rojo.

- Ahora el relleno. Se cumple la regla porque tienen todas distinto relleno: rayado, vacío y pintado.

- Por último, para la cantidad, se cumple la regla porque son tres números distintos: 2, 1 y 3

Entonces, como la regla se cumple para todas las características, estas tres cartas forman un SET.

3) Mezcla de iguales y distintas

Prestá atención en este ejemplo que tiene una diferencia.

- Para la forma se cumple la regla “todas iguales o todas distintas" porque tienen todas la misma forma: son todas óvalos.

- Sigamos con el color. Se cumple la regla porque todas tienen colores distintos: verde, azul y rojo.

- Ahora el relleno. Se cumple la regla porque tienen todas el mismo relleno: son todas así, rayadas.

- Y por último la cantidad, se cumple la regla porque los tres números son distintos: 2, 1 y 3.

Entonces, como la regla se cumple para todas las características, estas tres cartas forman un SET.

4) Una característica rompe la regla

Ahora veamos este último ejemplo.

- Se cumple la regla “todas iguales o todas distintas” para la forma, porque son todas distintas: Óvalo, diamante y viborita

- Y para el color, no se cumple la regla. No son ni todas iguales ni todas distintas: hay dos verdes iguales y una azul distinta. Entonces, para el color no se cumple la regla.

Como una de las características no cumple la regla, entonces estas tres cartas ya no forman un SET.
